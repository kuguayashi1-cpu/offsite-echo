# OFFSITE · 场的回声（网页版）

微信小游戏《场的回声》的浏览器移植版。源项目 `D:\MINIGAME-2` 未改动；本目录为独立 HTML 网页。

摄像头通过浏览器 `getUserMedia` 调用。GitHub Pages 提供 HTTPS，手机与电脑浏览器都可以授权摄像头。

## 玩法

限时 60 秒的灰度对频得分游戏：

1. PRESS START 进入游戏
2. 点 **START SCAN**，在浏览器弹窗中允许摄像头
3. 点 **PLAY** 开始一局
4. 画面给出 **TARGET** 目标音阶（10 档之一）
5. 把镜头中心 ROI 对准相应明暗，使主音色与目标一致
6. 锁定条充满即得分；连续命中有连击加分
7. 时间结束显示 SCORE / BEST，点 **RETRY** 再来一局

计分：基础 100 分 + 连击 × 25。偏离目标超过约 0.65 秒连击清零。最高分写入浏览器本地存储。

## 摄像头说明

- 必须由点击 **START SCAN** 触发授权（浏览器安全限制）
- 需要 HTTPS 或 localhost；直接用 `file://` 打开通常无法开摄像头
- 手机优先后置摄像头，电脑使用默认摄像头

## 本地预览

在本目录启动一个静态服务器，例如：

```bash
npx --yes serve .
```

然后打开提示的本地地址。
